# Data Model: Gestión de usuarios y recursos

## Usuario

| Campo | Tipo Java | Columna | Restricciones |
|---|---|---|---|
| id | `Long` | `id` | PK, autoincremental |
| nombre | `String` | `nombre` | `nullable=false`, `length=100` |
| documento | `String` | `documento` | `nullable=false`, `unique=true`, `length=30` |
| correo | `String` | `correo` | `nullable=false`, `unique=true`, `length=120`, formato email |
| estado | `EstadoUsuario` | `estado` | `nullable=false`, `EnumType.STRING`, `length=20` |

### Enum `EstadoUsuario`

```java
ACTIVO,
INACTIVO
```

### Reglas

- Al crear, `estado = ACTIVO`.
- `documento` y `correo` son únicos.
- No se elimina físicamente; solo se cambia el estado.
- El cambio de estado no afecta reservas existentes.

## Recurso

| Campo | Tipo Java | Columna | Restricciones |
|---|---|---|---|
| id | `Long` | `id` | PK, autoincremental |
| nombre | `String` | `nombre` | `nullable=false`, `length=100` |
| descripcion | `String` | `descripcion` | `nullable=true`, `length=255` |
| tipo | `String` | `tipo` | `nullable=false`, `length=50` |
| capacidad | `Integer` | `capacidad` | `nullable=false`, `> 0` |
| estado | `EstadoRecurso` | `estado` | `nullable=false`, `EnumType.STRING`, `length=25` |

### Enum `EstadoRecurso`

```java
DISPONIBLE,
MANTENIMIENTO,
FUERA_DE_SERVICIO
```

### Reglas

- Al crear, `estado = DISPONIBLE`.
- `capacidad > 0`.
- `tipo` es texto libre.
- La modificación de datos no cambia el estado.
- El cambio de estado no cancela reservas existentes.

## DDL de referencia

```sql
CREATE TABLE usuarios (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    nombre VARCHAR(100) NOT NULL,
    documento VARCHAR(30) NOT NULL UNIQUE,
    correo VARCHAR(120) NOT NULL UNIQUE,
    estado VARCHAR(20) NOT NULL
);

CREATE TABLE recursos (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    nombre VARCHAR(100) NOT NULL,
    descripcion VARCHAR(255),
    tipo VARCHAR(50) NOT NULL,
    capacidad INTEGER NOT NULL CHECK (capacidad > 0),
    estado VARCHAR(25) NOT NULL
);
```

Hibernate genera el esquema con `ddl-auto=create-drop`; el DDL anterior es de referencia para revisión.
